# 채묵 — 튜토리얼 장치 (클라이언트)

**관문 내용은 [TUTORIAL-GATES.md](TUTORIAL-GATES.md)가 기준이다.** 이 문서는 그 관문을 꽂는 클라이언트 장치만 적는다.
튜토리얼은 "막혔는지 감지"가 아니다. 정해진 이야기 지점에 일부러 막히는 구간을 두고, 그 순간 먹동이의 혼잣말이나
NPC 대사로 방법을 알려 준다. 사망 횟수, 레벨 차이, 공격 횟수 같은 적응형 조건은 쓰지 않는다.

## 생각 말풍선 (`src/game/ui/hints.ts`, `Hints`)
- `think(id, text, { key?, urgent?, repeat? })`: 먹동이의 혼잣말 한 줄. 화면 왼쪽 위, 초상 아래에 약 4초. 모달 없음, 일시정지 없음.
- 계정당 한 번: `localStorage`의 `ink.hints.<account>`에 본 id 목록. `has(id)`, `mark(id)`.
- 간격 20초, 전투가 한창이면(최근 3초 안에 맞음, 2초 안에 휘두름, 대화·창이 열림) 미룬다. 관문 힌트는 `urgent`로 바로 뜬다.
- 글리프: 키보드는 생각 끝에 작은 키 표시(`KEYS`, `src/game/ui/input.ts`), 터치는 키 대신 해당 화면 버튼이 빛난다(`hint-glow`).

## 점진 공개 (`Hud.reveal(part, bloom)`)
| UI | 나타나는 때 |
|---|---|
| 수련 버튼 | 처음 수련 포인트가 생겼을 때 |
| 장비 버튼, 안료/묵옥 | 처음 안료나 묵옥을 얻었을 때, 또는 이야기가 단이에게 닿았을 때 |
| 물약 호리병 | 처음 피해를 입었을 때 |
| 자동 버튼 | 관문 2 (c1q3 중 죽림에서 세 번째 처치), 이미 지난 계정은 바로 |
| 검법 칸 | 처음부터 희미한 실루엣 + `Lv N`, 누르면 짧은 생각. 익히는 레벨업에 그 색으로 피어남 |

공개 상태는 같은 저장소에 `ui:<part>`로 남는다. 처음 접속할 때 자동으로 뜨던 키 안내는 없다(H로 연다).

## 관문 연결 (`src/game/game.ts`)
| 관문 | 어디에 걸려 있나 |
|---|---|
| 1 부푼 먹방울 | `checkHints()`: c1q3, 죽림, `bigblob`이 `wind` |
| 2 자동 전투 | `showHits()`: c1q3, 죽림, 세 번째 처치 |
| 3 먹덩굴 | `checkHints()`: 살아 있는 덩굴에 닿음(Lv4 전/후 다른 생각). 덩굴 충돌은 `Monsters.obstacles` → `Field.dynamic` |
| 4 먹 갑옷 | `showHits()`: c1q5, `shadelord`에 `resisted` |
| 5 먹두꺼비 탄 | `Monsters.onEffect("shot")`: c1q7 |
| 6 대먹귀 +3 | `showHits()`: c1q10, 보스에 `resisted` → 다음 수련 창은 강화 탭으로 열림 |
| 7 대먹귀 내려찍기 | `Monsters.onEffect("slam")`: 먹봉우리, c1q10 |

그 밖에 남은 한 번짜리 순간: 검법을 익히는 레벨업(그 칸이 피어나며 생각), 첫 죽음(다시 일어나기 화면의 한 줄, 다음에 단이가 물약 이야기), 수련 창 각 탭의 첫 열람 한 줄.

## 막힘 피드백
- `resisted` 결과: 피해 숫자 대신 회색 "먹혀들지 않는다"(피해가 조금 들어가면 숫자와 함께), 회색 튕김 불꽃.
- 덩굴: 먹 가시덤불, 죽으면 불씨와 재로 타 없어지고, 다시 날 때 자라 오른다.
- 그림자 무사: 큰 몸, 어두운 기운, 머리 위 이름패.
- 부푼 먹방울: 기운을 모으며 부풀고, 바닥에 붉은 원.

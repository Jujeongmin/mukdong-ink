제목: [개발일지 1일차] 채묵: 잃어버린 색 — 수묵화인데 손맛 좋은 액션 RPG 만들기

수묵화 느낌 게임들이 요즘 신박해 보이는데, 막상 해 보면 그림은 예쁜데 때리는 맛이 심심한 게 많았음.
그래서 첫 기획 계기는 딱 하나였음. **"수묵화 게임인데 타격감이 좋은 게임."**
붓으로 베면 먹이 튀고, 손에 착 붙는 느낌. 이걸 목표로 1일차 달려 봄.

이름은 「채묵: 잃어버린 색」. 웹(Verse8)에 채널제 멀티 RPG로 낼 생각.
세상은 전부 먹과 종이고, 색은 검법을 쓸 때랑 물들인 천에만 남아 있음.

1) 모션은 손으로 안 짜고 모션캡처 씀
- 처음엔 키프레임을 코드로 짰는데 영 어색해서 갈아엎음.
- 무료(CC0) 모션캡처 팩에서 검 3연타를 골라 주인공 뼈대에 옮겨 붙임.
- 1·2타는 1.25배, 3타는 1.55배 빠르게 잘라서 무협 느낌 나게 함.

2) 맞는 순간에 다 몰아줌
- 피해 숫자, 먹 튐, 소리를 서버 응답 시점이 아니라 **붓이 실제로 닿는 프레임**에 맞춤.
- 맞을 때 0.05초 정도 멈칫(히트스톱) + 살짝 화면 흔들림. 처치는 0.07초.
- 세게 칠수록 먹이 크게 튀고, 3타는 원을 그리며 휩쓸고 먹꽃이 핌. 처치하면 먹이 터지고 종잇조각이 날림.
- 붓끝을 따라 서예 획 같은 먹 리본 궤적이 남음.

3) 피하는 맛
- 스페이스로 구르기. 구르는 동안 진짜로 무적(서버에서도 판정).
- 몬스터가 내려찍기 전에 바닥에 붉은 먹 원이 먼저 그려져서, 보고 굴러서 피하는 게 핵심.

4) 소리
- 붓 휘두르는 소리 3종, 먹 괴물 타격음, 처치 시 먹 터지는 소리, 구르기, 스킬 5종 전부 따로 넣음.

---- 이야기 ----

세상은 원래 다섯 빛으로 그려진 한 폭의 그림이었는데, 먹 한 방울 '번짐'이 첫 붓 오방붓을 다섯 조각으로 부러뜨리고 색을 다 마셔 버림.
1장 「물빛 조각」, 2장 「불빛 조각」까지 만듦. 퀘스트는 NPC랑 대화해서 받고 넘기고, 대화창에 NPC 얼굴이 뜸.

[c2-kiln.jpg] [c2-temple.jpg] [c2-censer.jpg]
2장 지역. 옛 가마터, 불탄 절터, 보스가 있는 향로 마당.

---- 튜토리얼 ----

설명창 우다다 띄우는 대신, 정해진 지점에 일부러 막히는 구간을 넣음.
예) 덩굴이 길을 막는데 일반 공격은 안 먹힘 → 불 검법을 배우면 태울 수 있음.
예) 보스가 단단해서 피해가 거의 안 들어감 → 붓을 강화해야 뚫림.
막히는 순간 주인공이 혼잣말로 살짝 힌트를 줌.

---- AI로 만든 방식 ----

- 코드: Claude Code로 서버, 클라이언트, 그래픽, UI 담당 에이전트를 나눠서 동시에 돌림.
- UI 먹 테두리, 붓 획, 아이콘: Codex로 생성 후 먹 부분만 남겨서 마스크로 씀.
- 배경음악(국악기 구성) 8곡, 효과음 50개 정도: PixelLab으로 생성. 코드로 합성한 소리는 하나도 안 씀.
- 모션: CC0 모션캡처 팩을 뼈대에 이식.
- 로딩 화면은 처음에 AI 그림을 넣었다가, 그림이 게임보다 너무 좋아 보여서 빼고 게임 화면을 그대로 찍어서 씀.
